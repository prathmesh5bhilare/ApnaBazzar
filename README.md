# ApnaBazzar (React + React Router SPA)

1. Install Node.js (nodejs.org)
2. Open this folder in VS Code terminal
3. npm install
4. npm run dev
5. Open http://localhost:5173

Coupon code to try in cart: APNA10

Real photos: put images in public/images and add `image: "/images/xyz.jpg"` to a product in src/components/products.js
